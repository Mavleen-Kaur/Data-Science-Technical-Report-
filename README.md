# CSC-44112: Advanced Applications of AI and ML
## Assessment Part 2: Technical Data Science Report

### Project Title
News Article Classification Using Machine Learning:
A Comparative Study of TF-IDF Based Models on the AG News Dataset

---

### Project Overview
This project implements and compares three classical machine learning models
for automatic news article classification using the AG News dataset.
The models classify news articles into four categories:
World, Sports, Business, and Science/Technology.

---

### Dataset
- **Name:** AG News Dataset
- **Source:** https://huggingface.co/datasets/fancyzhx/ag_news
